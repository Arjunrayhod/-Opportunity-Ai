# 🚀 Opportunity AI — Affordable Course Marketplace & Market Intelligence Platform

A production-grade, mobile-first Android & Web platform combining **Affordable In-Demand Courses** (CapCut Video Editing, YouTube Growth, AI Freelancing, Price Action Trading, Cybersecurity, Fitness), **Market Intelligence & Risk Scenarios**, and **Student Earning Gigs** with a full Web Admin CMS.

---

## ✨ Key Platform Features

### 🎓 1. Affordable Course Academy & ₹0 Video Streaming
* **High Demand / Low Price**: Courses at ₹99, ₹149, ₹199 vs ₹4,999+ elsewhere.
* **30GB+ Video Streaming**: Ad-free YouTube Unlisted & Google Drive embedded custom video player.
* **Downloadable PDFs & Quizzes**: Cheat sheets, notes, and interactive module knowledge checks.

### 🛡️ 2. Anti-Piracy & Content Security
* **Android `FLAG_SECURE`**: Completely blocks screen recording (AZ Recorder, Mobizen) and screenshots (outputs black screen).
* **MT Manager Defense**: Signature verification and code obfuscation to prevent APK reverse-engineering.
* **1-Device Login**: Single active session per student account.

### 💰 3. 7 Viral & Monetization Engines
1. **"Refer Karo aur Kamao" Affiliate**: Earn ₹20 wallet reward per friend referral or unlock free courses.
2. **Automated Completion Certificate**: Generate professional certificates for LinkedIn & Instagram stories.
3. **Combo Bundle Deals**: "All-in-One Creator Pass" (3 courses for ₹249).
4. **Daily Streak Coins**: Gamified daily learning rewards (100 coins = ₹20 discount coupon).
5. **Direct VIP WhatsApp Community Link**: Permanent 1-click broadcast channel join.
6. **Flash Sale Countdown Timer**: FOMO timer banner driving impulse checkout.
7. **1-Tap PDF Cheat Sheet Vault**: Viral hooks, candlestick guides, and workout charts.

### 📊 4. Super Admin CMS & Student CRM (`/admin`)
* Dynamic Course Creator (add, edit, change pricing, publish instantly).
* Student Buyers CRM with 1-click **Export to Excel (.CSV)**.
* 1-Click **Full Database Backup (.JSON)** & Restore.
* Push Notification Broadcaster.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build Production Web App
```bash
npm run build
```

### 4. Build Android App
```bash
npm run android:init   # First time only
npm run android:sync   # Sync web code to Android
npm run android:open   # Open in Android Studio to build APK
```
