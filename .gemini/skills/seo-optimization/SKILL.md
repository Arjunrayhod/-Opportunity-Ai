# SEO & Discovery Optimization Skill

## Core Requirements
1. **Semantic HTML5**: Ensure proper landmark elements (`<header>`, `<main>`, `<nav>`, `<footer>`, `<article>`).
2. **Metadata**: Set high-intent `<title>`, `<meta name="description">`, and canonical `<link rel="canonical">` on every route.
3. **OpenGraph & Twitter Cards**: Provide `og:title`, `og:description`, `og:image` ($1200\times 630\text{px}$), and `twitter:card`.
4. **Structured Data**: Embed Schema.org JSON-LD for Courses (`@type: Course`), Organizations, and FAQ pages.
